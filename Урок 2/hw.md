# 🧪 Итоговый тест по Python (Уроки 1-2)

Привет! Это тестовое практическое задание только по первым двум урокам.

Здесь проверяются темы:

- функции и аргументы
- строковые методы
- работа со списками
- обработка ошибок через `try/except`

---

## 📚 Тема проекта: Мини-список учеников

Напиши программу, которая работает со списком имён и оценок.

---

## Часть 1 - Функции

### 1. Функция приветствия

Создай функцию:

```python
def greet(name: str, greeting: str = "Salam Aleikum") -> str:
```

Она должна возвращать строку:

```
Salam Aleikum, Arstan
```

Если передан второй аргумент, используй его как приветствие.

---

### 2. Функция подсчёта среднего

Создай функцию:

```python
def average_score(scores: list[int]) -> float:
```

Требования:

- Верни среднее арифметическое
- Если список пустой, выбрось `ValueError` с понятным текстом

---

## Часть 2 - Строковые методы

Создай функцию:

```python
def normalize_name(name: str) -> str:
```

Она должна:

- убрать пробелы по краям
- сделать первую букву заглавной, остальные строчными

Примеры:

```python
normalize_name("  arSTan ")   # "Arstan"
normalize_name(" aLiYA")      # "Aliya"
```

---

## Часть 3 - Работа со списками

Создай функцию:

```python
def repeat_names(names: list[str], times: int) -> list[str]:
```

Требования:

- Верни новый список, где каждое имя повторяется `times` раз
- Используй цикл
- Если `times <= 0`, выбрось `ValueError`

Пример:

```python
repeat_names(["Aliya", "Bek"], 2)
# ["Aliya", "Aliya", "Bek", "Bek"]
```

---

## Часть 4 - Обработка ошибок

Сделай интерактивный блок с вводом индекса:

1. Есть список:

```python
students = ["Aliya", "Bek", "Nura", "Ayan"]
```

2. Программа спрашивает индекс у пользователя.

3. Нужно обработать ошибки:

- если введено не число -> сообщение: `Введите целое число!`
- если индекс вне диапазона -> сообщение: `Такого индекса нет!`

4. Если всё хорошо, выведи имя по индексу.

---

## Часть 5 - Главное меню

Сделай меню в цикле `while True`:

```
1 - Добавить имя
2 - Показать все имена
3 - Повторить имена N раз
4 - Показать имя по индексу
5 - Выйти
```

Требования:

- Имена добавляй в список после `normalize_name(...)`
- Для пункта 3 считай число повторов через `input()` и обработай `ValueError`
- Для пункта 4 используй логику из части 4
- При неверном пункте меню выводи понятное сообщение, программа не должна падать
