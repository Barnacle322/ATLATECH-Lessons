# 📦 Домашнее задание — Урок 6

## Личный помощник

Ты создашь маленькое приложение из нескольких модулей, объединённых в пакет. Каждый модуль отвечает за свою задачу — как в настоящем проекте!

---

## Структура проекта

Создай следующую структуру папок и файлов:

```
assistant/
│
├── main.py
└── tools/
    ├── __init__.py
    ├── calculator.py
    ├── notes.py
    └── info.py
```

> 💡 `__init__.py` оставь пустым. `main.py` находится **рядом** с папкой `tools`, не внутри!

---

## Модуль 1 — `tools/calculator.py`

Напиши следующие функции:

**`add(a, b)`**, **`subtract(a, b)`**, **`multiply(a, b)`**, **`divide(a, b)`**

- Все четыре выполняют соответствующую математическую операцию и возвращают результат
- `divide` должна обработать деление на ноль — вместо ошибки возвращай строку `"Ошибка: деление на ноль"`

**`calculate() -> None`**

Функция которая спрашивает у пользователя два числа и операцию, затем выводит результат:

```
Введите первое число: 10
Введите второе число: 3
Выберите операцию (+, -, *, /): *
Результат: 30
```

Обработай `ValueError` если пользователь вводит не число.

## Модуль 2 — `tools/notes.py`

Заметки сохраняются в файл `notes.txt`.

**`add_note(text: str) -> None`**

- Открывает `notes.txt` в режиме добавления и записывает заметку с датой:

```
[15.01.2024] купить продукты
```

> 💡 Используй `datetime` из стандартной библиотеки для даты!

**`load_notes() -> list[str]`**

- Читает `notes.txt` и возвращает список заметок
- Если файл не существует — возвращает пустой список (обработай `FileNotFoundError`)

**`show_notes() -> None`**

- Загружает все заметки через `load_notes()`
- Выводит каждую заметку с номером:

```
1. [15.01.2024] купить продукты
2. [15.01.2024] позвонить маме
```

- Если заметок нет — выводит `"Заметок пока нет"`
- Используй **генератор списка** чтобы пронумеровать заметки

**`search_notes(keyword: str) -> None`**

- Загружает все заметки и выводит только те, которые содержат `keyword`
- Используй **генератор списка** для фильтрации
- Если ничего не найдено — выводи `"Ничего не найдено"`

## Модуль 3 — `tools/info.py`

**`greet(name: str) -> str`**

- Возвращает приветствие в зависимости от времени суток:

```
Доброе утро, Арстан!    # 6:00 - 12:00
Добрый день, Арстан!    # 12:00 - 18:00
Добрый вечер, Арстан!   # 18:00 - 23:00
Доброй ночи, Арстан!    # 23:00 - 6:00
```

> 💡 Используй `datetime.now().hour` чтобы узнать текущий час!

**`show_info() -> None`**

- Выводит текущую дату и время в красивом формате:

```
📅 Сегодня: 15.01.2024
🕐 Время: 14:32
```

## `main.py` — Главное меню

Собери всё вместе в одном файле. Импортируй нужные функции из пакета `tools` и запусти меню:

```
Добрый день, Арстан!

Выберите раздел:
1 - Калькулятор
2 - Заметки
3 - Информация
4 - Выйти
```

При выборе **раздела 2** показывай подменю:

```
1 - Добавить заметку
2 - Показать все заметки
3 - Найти заметку
4 - Назад
```

Не забудь про `if __name__ == "__main__"` в `main.py`!
