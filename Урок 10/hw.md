## Задача 1 — GitHub API

**URL:** `https://api.github.com/users/{username}`

Напиши функцию `get_github_user(username: str) -> None` которая:

- Делает GET запрос по адресу выше
- Выводит следующую информацию о пользователе:

```
👤 Имя: Arstan
📦 Репозиториев: 12
👥 Подписчиков: 5
📍 Локация: Bishkek, Kyrgyzstan
🔗 Профиль: https://github.com/Barnacle322
```

- Обработай случай когда пользователь не найден (`status_code == 404`)
- Обработай `ConnectionError` если нет интернета
- Если поле `location` пустое — выводи `"Не указана"` вместо `None`

> 💡 Подсказка: `data.get("location") or "Не указана"` — элегантный способ обработать пустое поле

Протестируй на нескольких пользователях:

```python
get_github_user("Barnacle322")
get_github_user("несуществующий123456")
```

## Задача 2 — PokeAPI

**URL:** `https://pokeapi.co/api/v2/pokemon/{name}`

Напиши функцию `get_pokemon(name: str) -> None` которая:

- Делает GET запрос по адресу выше
- Выводит информацию о покемоне:

```
🎮 Покемон: Pikachu
📏 Рост: 4 (дм)
⚖️ Вес: 60 (гг)
⚡ Типы: electric
💪 Способности: static, lightning-rod
```

- Используй **генератор списка** чтобы извлечь типы покемона из ответа
- Используй **генератор списка** чтобы извлечь способности покемона из ответа
- Обработай случай когда покемон не найден
- Имя покемона выводи с заглавной буквы

> 💡 Подсказка: типы находятся в `data["types"]` — это список словарей. Загляни в структуру ответа через `print(data["types"])` чтобы понять как добраться до названия типа.

Протестируй:

```python
get_pokemon("pikachu")
get_pokemon("charizard")
get_pokemon("несуществующий")
```

## Задача 3 — REST Countries API

**URL:** `https://restcountries.com/v3.1/name/{country}`

Напиши функцию `get_country(name: str) -> None` которая:

- Делает GET запрос по адресу выше
- Выводит информацию о стране:

```
🌍 Страна: Kyrgyzstan
🏛️ Столица: Bishkek
👨‍👩‍👧‍👦 Население: 6,527,743
🌐 Регион: Asia
💰 Валюта: Kyrgystani som (сом) — KGS
```

- Население выводи с разделением тысяч через запятую: `6,527,743`
- Валюту найди в `data["currencies"]` — это словарь словарей
- Обработай случай когда страна не найдена
- Обрати внимание — API возвращает **список**, бери первый элемент: `data[0]`

> 💡 Подсказка для населения: `f"{population:,}"` автоматически добавляет разделители тысяч!

Протестируй:

```python
get_country("kyrgyzstan")
get_country("germany")
get_country("несуществующая")
```

## Задача 4 — Open Weather API

**URL:** `https://api.openweathermap.org/data/2.5/weather?q={city}&appid={api_key}&units=metric&lang=ru`

> ⚠️ Этот API требует бесплатной регистрации. Зарегистрируйся на [openweathermap.org](https://openweathermap.org/api) и получи бесплатный API ключ. Ключ активируется в течение ~10 минут после регистрации.

Напиши функцию `get_weather(city: str, api_key: str) -> None` которая:

- Делает GET запрос по адресу выше
- Выводит погоду в городе:

```
🌤️ Погода в Бишкеке:
🌡️ Температура: 18°C (ощущается как 16°C)
💧 Влажность: 45%
💨 Ветер: 3.5 м/с
☁️ Описание: переменная облачность
```

- Обработай случай когда город не найден (`status_code == 404`)
- Обработай `ConnectionError`

Протестируй:

```python
get_weather("Bishkek", "твой_api_ключ")
get_weather("London", "твой_api_ключ")
```
