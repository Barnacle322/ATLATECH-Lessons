HTTP/HTTPS -> HyperText Transfer Protocol (Secured) (Протокол передачи гипертекста)
DNS -> Domain Name Server(mapping IP address <-> Domain)
JSON -> JavaScript Object Notation
API -> Application Programming Interface(Интерфейс Программирования Приложения)

Для базового сайта нужны следующие технологии
HTML -> HyperText Markup Language (Язык гиперотекстовой разметки)
CSS -> Cascading StyleSheets(Каскадные Страницы Стилей)
JS -> JavaScript

1. User clicks on a link(https://www.google.com) in a browser
2. Browser makes a request to DNS
3. DNS responds google = 8.8.8.8
4. Browser make a request to 8.8.8.8
5. 8.8.8.8 responds with HTML/CSS/JS/Photos/Videos/JSON etc
