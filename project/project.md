# 🚀 Проект — Блок 1

## Правила

- Проект **индивидуальный** — каждый делает свой
- Срок: **1 неделя**
- Тему выбираешь **сам** из списка ниже — или предлагаешь свою (согласуй с преподавателем)
- Код должен быть **твоим** — не копируй готовые решения из интернета

---

## Обязательные требования

Независимо от выбранной темы, проект **должен** содержать:

| Требование                       | Что это значит                            |
| -------------------------------- | ----------------------------------------- |
| Минимум **2 класса**             | С атрибутами, методами и `__str__`        |
| **Наследование**                 | Хотя бы один дочерний класс с `super()`   |
| **Пакет**                        | Код разбит на модули в отдельной папке    |
| **Файловый I/O**                 | Данные сохраняются и загружаются из файла |
| **Обработка ошибок**             | `try/except` там где может сломаться      |
| **Генератор списка или словаря** | Хотя бы один раз осмысленно               |
| `if __name__ == "__main__"`      | В `main.py`                               |

---

## Идеи для проекта

### 💰 Трекер бюджета

Записывай доходы и расходы по категориям. Считай баланс, показывай статистику по категориям, предупреждай если баланс уходит в минус. Классы: `Transaction`, `Expense(Transaction)`, `Income(Transaction)`.

---

### 🎮 Текстовая RPG

Простая пошаговая битва между персонажами. Герой против врагов, очки здоровья, атаки, победа/поражение. Результаты сохраняются в файл. Классы: `Character`, `Hero(Character)`, `Enemy(Character)`.

---

### 🏋️ Дневник тренировок

Записывай тренировки по дням — упражнения, подходы, вес. Показывай прогресс, считай общий объём за неделю. Классы: `Exercise`, `Workout`.

---

### 💡 Своя идея

Есть что-то что хочется сделать? Предложи свою идею — главное чтобы она покрывала обязательные требования.

---

## Структура проекта

Организуй код примерно так (названия папок под твою тему):

```
my_project/
│
├── main.py
├── README.md          ← опиши что делает твой проект (2-3 предложения)
└── core/
    ├── __init__.py
    ├── models.py      ← классы
    ├── storage.py     ← чтение/запись файлов
    └── utils.py       ← вспомогательные функции
```
