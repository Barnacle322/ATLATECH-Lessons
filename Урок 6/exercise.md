Не переживай если что-то покажется сложным — разбивай задачу на маленькие шаги и решай каждый по очереди. Ты справишься!

### Часть 1 — Класс `Book`

Создай класс `Book` со следующими атрибутами:

| Атрибут   | Тип    | Описание           |
| --------- | ------ | ------------------ |
| `title`   | `str`  | Название книги     |
| `author`  | `str`  | Автор книги        |
| `pages`   | `int`  | Количество страниц |
| `is_read` | `bool` | Прочитана ли книга |

**Конструктор** должен принимать `title`, `author`, `pages`. Атрибут `is_read` по умолчанию всегда `False` — книга же только что добавлена!

```python
# Пример создания объекта
book = Book("Дюна", "Фрэнк Герберт", 412)
```

### Часть 2 — Методы класса

Добавь в класс два метода:

#### `mark_as_read()`

Отмечает книгу как прочитанную (меняет `is_read` на `True`) и выводит сообщение:

```
"Дюна" отмечена как прочитанная ✅
```

#### `short_info() -> str`

Возвращает строку с краткой информацией о книге:

```
Дюна — Фрэнк Герберт | 412 стр. | ✅ Прочитана
Властелин колец — Толкин | 1200 стр. | ❌ Не прочитана
```

> 💡 Подсказка: используй f-строку и тернарный оператор для статуса:
> `"✅ Прочитана" if self.is_read else "❌ Не прочитана"`

### Часть 3 — Сохранение в файл

Напиши функцию **вне класса** `save_books(books: list) -> None`, которая:

- Открывает файл `library.txt` в режиме записи (`"w"`)
- Сохраняет каждую книгу в формате: `Название:Автор:Страницы:Прочитана`

```
Дюна:Фрэнк Герберт:412:True
Властелин колец:Толкин:1200:False
```

---

### Часть 4 — Загрузка из файла

Напиши функцию **вне класса** `load_books() -> list`, которая:

- Читает файл `library.txt`
- Создаёт объект `Book` для каждой строки
- Возвращает список объектов `Book`
- Если файл не существует — возвращает пустой список (обработай `FileNotFoundError`)

> 💡 Подсказка: не забудь что `is_read` сохранён как строка `"True"` или `"False"`. Преобразуй её обратно в `bool`:
> `is_read = saved_value == "True"`

---

### Часть 5 — Главное меню

Напиши меню в виде цикла `while`:

```
1 - Добавить книгу
2 - Отметить книгу как прочитанную
3 - Показать все книги
4 - Выйти
```

- При выборе **2** спроси название книги и найди её в загруженном списке
- Если книга не найдена — выведи понятное сообщение об ошибке
- При вводе некорректного числа программа не должна падать — обработай `ValueError`
