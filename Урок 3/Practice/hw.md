# 📚 Домашнее задание — Урок 3

## Телефонная книга

Вы создаёте простую телефонную книгу, которая сохраняет контакты в файл и умеет их искать.

---

### Что нужно сделать

#### Часть 1 — Добавление контактов

Напишите функцию `add_contact(name: str, phone: str) -> None`, которая:

- Открывает файл `contacts.txt` в режиме добавления (`"a"`)
- Записывает контакт в формате `Имя:Номер` на отдельной строке

```
Арстан:+996700123456
Алия:+996555987654
```

---

#### Часть 2 — Загрузка контактов

Напишите функцию `load_contacts() -> dict[str, str]`, которая:

- Читает файл `contacts.txt`
- Возвращает словарь, где ключ — имя, значение — номер телефона
- Использует **генератор словаря** для построения результата
- Если файл не существует — возвращает пустой словарь (обработайте `FileNotFoundError`)

---

#### Часть 3 — Поиск контакта

Напишите функцию `find_contact(name: str) -> None`, которая:

- Загружает контакты через `load_contacts()`
- Ищет имя в словаре (обработайте случай, когда контакт не найден через `KeyError`)
- Выводит номер телефона, если контакт найден

---

#### Часть 4 — Вывод всех контактов

Напишите функцию `list_contacts() -> None`, которая:

- Загружает все контакты
- Выводит только те контакты, у которых номер начинается с `+996` (используйте **генератор списка**)
- Если контактов нет — выводит сообщение `"Телефонная книга пуста"`

---

#### Часть 5 — Главное меню

Напишите простое меню в виде цикла `while`, которое предлагает пользователю:

```
1 - Добавить контакт
2 - Найти контакт
3 - Показать все контакты
4 - Выйти
```

При вводе некорректного числа (например, буквы) программа не должна падать — обработайте `ValueError`.

---

### Пример работы программы

```
Выберите действие: 1
Введите имя: Арстан
Введите номер: +996700123456
Контакт сохранён!

Выберите действие: 2
Введите имя: Арстан
Номер Арстан: +996700123456

Выберите действие: 2
Введите имя: Жантай
Контакт 'Жантай' не найден.

Выберите действие: 3
Арстан: +996700123456

Выберите действие: 4
До свидания!
```

---

### Подсказки

- Для разбивки строки `"Арстан:+996700123456"` используйте `.split(":")`
- Режим открытия файла `"a"` добавляет строки в конец, не стирая старые данные
- `with open(...) as file:` автоматически закрывает файл — всегда используйте именно этот способ
- Генератор словаря выглядит так: `{k: v for k, v in ...}`
