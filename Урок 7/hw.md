### Часть 1 — Базовый класс `Animal`

Создай класс `Animal` со следующими атрибутами:

| Атрибут | Тип   | Описание      |
| ------- | ----- | ------------- |
| `name`  | `str` | Имя животного |
| `age`   | `int` | Возраст       |

Добавь метод `speak() -> None`, который выводит:

```
...
```

_(просто три точки — базовый класс не знает как говорит животное)_

Добавь `__str__` который возвращает:

```
Барсик, 3 лет
```

```python
# Проверь себя:

print(animal)       # Барсик, 3 лет

```

### Часть 2 — Класс `Dog`

Создай дочерний класс `Dog(Animal)`.

- Конструктор через `super()`
- Переопредели `speak()`:

```
Гав! Меня зовут Барсик
```

```python
# Проверь себя:
dog = Dog("Барсик", 3)

```

### Часть 4 — Общий список

Создай список со всеми тремя типами и пройдись по нему циклом, вызывая `speak()` на каждом:

```python
animals = [
    Animal("Животное", 1),
    Dog("Барсик", 3),
    Cat("Мурка", 5),
]

for animal in animals:
    animal.speak()
```

**Ожидаемый вывод:**

```
...
Гав! Меня зовут Барсик
Мяу! Меня зовут Мурка
```
