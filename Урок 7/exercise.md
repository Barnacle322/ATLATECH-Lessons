### Часть 1 — Класс `EBook`

Создай дочерний класс `EBook`, который наследует `Book` и добавляет:

- Атрибут `file_size_mb: float` — размер файла в мегабайтах
- Конструктор через `super()`
- Переопределённый `__str__`:

```
Дюна — Фрэнк Герберт | 412 стр. | 15.3 MB
```

### Часть 2 — Класс `AudioBook`

Создай дочерний класс `AudioBook`, который наследует `Book` и добавляет:

- Атрибут `duration_hours: float` — длительность в часах
- Конструктор через `super()`
- Переопределённый `__str__`:

```
Дюна — Фрэнк Герберт | 412 стр. | 8.5 часов
```

-----

### Часть 3 — Общий список

Создай список, в котором **вместе** лежат объекты всех трёх типов:

```python
catalog = [
    Book("Властелин колец", "Толкин", 1200),
    EBook("Дюна", "Фрэнк Герберт", 412, 15.3),
    AudioBook("Гарри Поттер", "Роулинг", 500, 8.5),
]
```

Пройдись по списку циклом и вызови `print()` на каждом объекте.
