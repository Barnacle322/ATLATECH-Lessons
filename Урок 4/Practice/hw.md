# 📚 Практическое задание — Урок 3

## Трекер расходов

Вы создаёте простой трекер расходов, который сохраняет траты в файл и умеет их анализировать.

---

### Что нужно сделать

#### Часть 1 — Добавление расхода

Напишите функцию `add_expense(category: str, amount: float) -> None`, которая:

- Открывает файл `expenses.txt` в режиме добавления (`"a"`)
- Записывает расход в формате `Категория:Сумма` на отдельной строке

```
Еда:1500
Транспорт:250.5
Еда:800
```

---

#### Часть 2 — Загрузка расходов

Напишите функцию `load_expenses() -> list[tuple[str, float]]`, которая:

- Читает файл `expenses.txt`
- Возвращает список кортежей вида `("Еда", 1500.0)`
- Использует **генератор списка** для построения результата
- Если файл не существует — возвращает пустой список (обработайте `FileNotFoundError`)

---

#### Часть 3 — Подсчёт по категориям

Напишите функцию `expenses_by_category() -> dict[str, float]`, которая:

- Загружает все расходы через `load_expenses()`
- Возвращает словарь, где ключ — категория, значение — **сумма всех трат** в этой категории
- Использует **генератор словаря** для построения результата

> 💡 Подсказка: сначала получите список уникальных категорий через `set()`, затем стройте словарь.

---

#### Часть 4 — Вывод статистики

Напишите функцию `show_stats() -> None`, которая:

- Выводит расходы по каждой категории (из части 3)
- Выводит общую сумму всех трат
- Выводит самую дорогую категорию
- Если расходов нет — выводит `"Расходов пока нет"`

```
Еда: 2300.0 сом
Транспорт: 250.5 сом
---
Итого: 2550.5 сом
Больше всего потрачено на: Еда
```

---

#### Часть 5 — Главное меню

Напишите простое меню в виде цикла `while`, которое предлагает пользователю:

```
1 - Добавить расход
2 - Показать статистику
3 - Выйти
```

При вводе суммы обработайте случай, когда пользователь вводит не число (`ValueError`). При вводе отрицательной суммы выведите сообщение об ошибке и не сохраняйте расход.

---

---

### Подсказки

- Для разбивки строки `"Еда:1500"` используйте `.split(":")`
- Чтобы преобразовать строку в число с плавающей точкой — используйте `float()`
- Уникальные категории можно получить так: `set(category for category, _ in expenses)`
- Генератор словаря выглядит так: `{k: v for k, v in ...}`
- Максимальное значение в словаре: `max(my_dict, key=my_dict.get)`
